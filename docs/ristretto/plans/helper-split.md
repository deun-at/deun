# helper-split — helper.dart opens in pieces

## Spec
- Source: idea — code review 2026-10-22 (research/code-review-2026-10.md), Architecture item: the As-is lines tagged "for helper-split" (lib/helper/helper.dart, 737 lines, 48 lib + 37 test importers, mixing error predicates, money/settled math, formatting, snackbars, push senders and navigation helpers; `isSettled`/`kSettledEpsilon` and `navigateToExpense`→`openLedgerExpense` already settled there)

## Approach
- Tier: easy — a pure move. Every symbol's file, the barrel's shape and the proof (the named existing suites, no new test) are pinned in this contract, so a planner would add nothing.
- Start only after notification-context-free has landed. Then compare helper.dart against the inventory in Decisions: the senders and the `UserRepository` import that only they used should already be gone. Cut each declaration with its doc comment into its module, unchanged. Trim each module's imports to what `flutter analyze` says it uses, and finally replace helper.dart's body with the exports. An `export` does not put a module in helper.dart's own scope, so while a declaration left in helper.dart still uses a moved symbol (`sendContactMail` uses `escapeHtml` until the last unit; `toCurrency` uses `kDefaultCurrencyCode` between the money and formatting moves), helper.dart also imports that module for that stretch. Each unit leaves the full suite green, so a red run points at one move. The usual failure would be a missing export or a missing sibling import, and the analyzer reports both.
- Two guards scan every .dart file under lib/: the € guard and the `homeCurrency`/exchange-rate scans (schema-baseline's lib/ scanners too, if it lands first, and they are path-blind the same way). The moved text passes both today: its only € sits in `openLedgerExpense`'s `///` doc comment, which the € guard skips. Keeping the moves verbatim keeps it that way.
- Likely touchpoints: lib/helper/helper.dart, lib/helper/money.dart (new), lib/helper/formatting.dart (new), lib/helper/ui_feedback.dart (new), lib/helper/navigation_helpers.dart (new), lib/helper/error_predicates.dart (new), lib/helper/escaping.dart (new), lib/helper/contact_mail.dart (new)
- Depends: notification-context-free
- Parallel-with: housekeeping, expense-search-escape, realtime-channel-lifecycle, group-model-parse-safety, schema-baseline, typed-expense-draft, editor-failure-keeps-form, scan-total-applies, group-write-rpcs, guest-merge-rpc, payback-atomic-recalc
- Not parallel, because they edit the same declarations or ask not to run alongside this: legacy-fallback-removal (it deletes `isMissingFunctionError`), typed-routes (the `extra:` maps in the navigation helpers), push-session-lifecycle, presentation-file-split and expense-editor-split (their plans ask not to). Whichever of a pair lands second rebases.
